# Oracle Place A2C RL experiment — 2026-11-10

## Model / task

Separate from the supervised grid-cell LSTM; it is **not yet a learned grid-cell navigation agent**. The Oracle policy receives a CNN visual embedding copied from pretrained vision weights, prior reward and action, ground-truth `current PC256 + HD12` code, and after initial goal reward, an oracle `goal PC256 + HD12` code. Policy LSTM256; synchronous A2C RMSprop; 32 parallel DMLab workers, 100 actions each per update, 4 simulator frames/action → **12,800 simulator frames per A2C update**.

Square arena 10×10 cells =2.5×2.5m. Episode lasts **5,400 DMLab frames = 90 seconds (60 fps)**. The hidden goal is newly sampled each episode, remains **fixed within that episode**, and after each successful hit (+10 reward) the agent teleports to a new starting cell (central 6×6). First goal discovery is exploratory; subsequent hits assess returning to the remembered location. The 500M *total training frames* span many episodes; NOT one 500M-frame episode.

## Coordinate convention incident — IMPORTANT

500M evaluation logs include `frame,x_m,y_m,goal_x_m_debug,goal_y_m_debug,goal_hit`; `goal_hit=1` denotes reward following an action but `x_m/y_m` were logged *before* that action. The `ORACLE.GOAL.XY` Y sign historically mismatched the actual player/physical goal coordinate frame. Diagnostic 500M normal+zero 1,344 reward events: uncorrected goal distance medians 1.172m and 1.345m; flipping **only goal debug Y** gives distance medians ~0.129m and ~0.126m, and 100% within 25cm. This strongly supports a coordinate mismatch, not evidence of arbitrary spawn-based rewards. Exact engine convention should still be verified with live raw world observations.

**Warning:** The Lua debug goal was also input to `goal_codes` at training time **without Y correction**. 50–500M learned models therefore used a reflected goal code. It is possible policy learned to compensate; this is NOT demonstrated. Preserve old checkpoints; fix coordinate reporting in a *versioned* new run and re-train independently, rather than resume historical weights under a new observation transform.
